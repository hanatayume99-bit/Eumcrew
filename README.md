# 이음크루

음악 합작 커뮤니티 사이트예요. 노래 공유, 정보·팁, 무페이 구인구직, 프로필·포트폴리오를 한곳에서 해요.
외부 패키지 없이 Node.js 내장 기능만 써서 **설치 과정이 없어요**.

## 실행

Node.js 22.13 이상이 필요해요. (`node -v`로 확인)

```bash
node server.js
# → http://localhost:3000
```

- 포트 바꾸기: `PORT=8080 node server.js`
- 데이터는 `data.db` 파일(SQLite)에 저장돼요. 이 파일만 백업하면 돼요.
- **가장 먼저 가입한 계정이 운영진**이 돼요. 운영진은 다른 사람의 글·댓글을 지울 수 있어요.
- 테스트: `node test.js` (임시 DB로 실제 요청을 보내 33개 항목 확인)

## 기능

| 메뉴 | 할 수 있는 일 |
| --- | --- |
| 노래 | 자작곡·커버·합작·리믹스 링크 공유. 유튜브 링크는 바로 재생, 그 외 사이트는 링크 버튼. 보컬·장르·태그, 좋아요, 댓글 |
| 정보·팁 | 작곡·믹싱·보컬·일러스트·영상·합작/행사 등 분류별 글, 참고 링크 |
| 구인구직 | 구인/구직, 분야, 마감일, 크레딧·수익 안내, 연락 방법. 마감 처리, 모집 중만 보기. 무페이 전용 안내 문구 |
| 멤버 | 분야별·"합작 가능" 필터로 사람 찾기 |
| 프로필 | 소개, 하는 일, 링크 5개, 합작 가능 표시, 올린 노래가 포트폴리오로 모임 |
| 공통 | 가입·로그인, 검색, 정렬(최신/좋아요/조회), 페이지 나누기, 모바일 화면 |

## 구조

```
server.js        서버 전체 (API, 인증, DB, 정적 파일)
public/          화면 (index.html, style.css, app.js — 해시 라우팅 SPA)
test.js          통합 테스트
data.db          실행하면 생기는 데이터 파일
```

## 보안 처리

- 비밀번호는 scrypt로 해시, 세션은 무작위 토큰(DB에는 해시만 저장), 쿠키는 HttpOnly + SameSite=Lax
- 변경 요청은 같은 출처 + JSON만 허용 (CSRF 방어), 로그인·가입에 횟수 제한
- 글·댓글은 화면에 항상 텍스트로만 넣어서 스크립트가 실행되지 않아요. 링크는 http(s)만 허용
- CSP 헤더로 외부 스크립트 차단 (유튜브 재생 화면만 허용)

## 실제로 열기 전에

1. **HTTPS 필수**: Nginx, Caddy, Cloudflare 같은 곳 뒤에 두고 `NODE_ENV=production node server.js`로 실행하면 쿠키에 Secure가 붙어요.
2. 프록시 뒤에서는 모든 요청의 IP가 같게 보여서 횟수 제한이 한꺼번에 걸릴 수 있어요. 공개 전에 프록시의 `X-Forwarded-For`를 읽도록 `rateLimit`을 손봐야 해요.
3. 지금은 **이메일 인증·비밀번호 찾기·신고 기능이 없어요.** 사람이 늘면 가장 먼저 필요한 기능이에요.
4. 노래는 **파일 업로드가 아니라 링크 공유**예요. 음원 파일을 직접 받으면 저장 공간, 저작권 신고 대응이 함께 필요해서 뺐어요.
5. 이용약관·저작권 정책(올린 사람 책임, 무단 사용 금지, 신고 절차)을 사이트에 적어 두는 걸 권해요.

## 사이트 이름 바꾸기

`public/index.html`의 `<title>`·푸터 문구, `public/app.js`의 `renderHeader`(로고 글자)를 고치면 돼요.
